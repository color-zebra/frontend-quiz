# Zubrilka (frontend-quiz)

База вопросов для подготовки к собеседованиям по фронтенду (`questions/`, `speech/`) и PWA-приложение для тренировки
поверх неё (`app/`, React + Vite). Сайт: https://color-zebra.github.io/frontend-quiz/. Пакетный менеджер — pnpm.

## Команды

Полный список и пояснения — в [README.md](README.md), раздел «Команды».

```
pnpm check        — проверить базу вопросов
pnpm app:build    — собрать базу и приложение, как при деплое
pnpm test:e2e     — собрать всё и прогнать сквозные тесты в Chrome
pnpm -F frontend-quiz-app e2e sets speech   — отдельные наборы тестов без пересборки (список — SUITES в app/e2e/run.mjs)
pnpm dev          — приложение локально
```

## Правила работы

- **Сначала план, согласованный с автором, потом код.** Работать этапами и показывать результат после каждого.
- **Коммитить и пушить только по просьбе автора.**
- **«Готово» подтверждать запуском,** а не словами: `pnpm check`, `pnpm app:build`, нужные наборы e2e, просмотр
  в браузере на ширине телефона (360–390 px). Честно писать, что прошло, что упало и что не проверено.
- **Обратная совместимость обязательна.** Старые наборы, резервные копии и сохранённые на устройствах данные
  продолжают работать. id вопросов и уроков не менять и не переиспользовать: к ним привязаны прогресс, заметки
  и закладки людей.
- **Учебный контент** (уроки, курсы, наборы) — только по правилам [plans/course-guide.md](plans/course-guide.md).
  Новую ошибку или подводный камень дописывать в его журнал.
- **Наборы пишутся сразу готовыми YAML-файлами.** Своих сборщиков, валидаторов и тестов к ним не строить: формат
  проверяет парсер приложения. Codex в проекте не используется.
- **Новый документ с планом или правилами** — добавить строкой в таблицу «Где что описано».
