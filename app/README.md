# Frontend Quiz — приложение

Тренажёр по базе вопросов из корня репозитория. React 19, TypeScript, Vite, CSS Modules.

## Запуск

Из корня репозитория:

```
pnpm install     — один раз
pnpm dev         — локальный сервер, адрес появится в терминале (обычно http://localhost:5173)
pnpm app:build   — проверка типов и сборка в app/dist
```

Чтобы открыть с телефона в той же Wi-Fi сети: `pnpm -F frontend-quiz-app dev --host`, затем адрес
вида `http://192.168.x.x:5173` из терминала. Экран ошибки загрузки в режиме разработки: добавить к адресу `?fail`.

## Что умеет

- Выбор тем, подтем и уровней, сессия на 10, 20, 30 вопросов или бесконечная. Последний выбор запоминается.
- Варианты перемешиваются. После ответа — пояснение к каждому варианту и общее объяснение механизма.
- Итог сессии: счёт, разбивка по темам, список ошибок, «прорешать ошибки ещё раз». Итог живёт в памяти
  и никуда не сохраняется.
- Заметки к вопросам в IndexedDB, экран «Мои заметки», выгрузка и загрузка файлом.
- Четыре темы оформления (Аврора, Графит, Терминал, Закат), выбор запоминается на устройстве.
- Клавиатура: 1–4 — ответ, Enter или → — дальше. Системная «Назад» возвращает на предыдущий экран;
  посреди сессии с ответами — показывает итог.

## Устройство

```
src/
  app/          корень: загрузка базы, стек экранов, связанный с историей браузера
  data/         типы базы, загрузка (пока заглушка stub.json из трёх вопросов)
  features/
    session/    фильтры, пул вопросов, очередь сессии
    notes/      заметки: IndexedDB, контекст, файл выгрузки
  screens/      экраны: home, session, question (карточка вопроса), summary, review, notes
  shared/       общие компоненты (стекло, кнопки, чипы, панель, разметка, подсветка кода) и утилиты
  theme/        список тем и панель выбора
  styles/       themes.css — переменные четырёх тем, global.css — сброс
```

Цвета, радиусы и шрифты компоненты берут только из переменных `styles/themes.css`. Тема включается атрибутом
`data-theme` на `<html>`. Скрипт в `index.html` ставит сохранённую тему до запуска React, чтобы при открытии
не мелькала тема по умолчанию.

Тексты вопросов рендерит react-markdown: разрешены только `код`, **жирный**, курсив и ссылки, HTML из текста
не исполняется. Код подсвечивает prism-react-renderer; SCSS и HTTP подключены из prismjs.

## Формат файла заметок

```json
{
  "format": "frontend-quiz-notes",
  "version": 1,
  "exportedAt": "2026-10-12T08:00:00.000Z",
  "notes": [
    {
      "key": "builtin:javascript-event-loop-002",
      "setId": "builtin",
      "questionId": "javascript-event-loop-002",
      "text": "Текст заметки",
      "updatedAt": 1760256000000,
      "snapshot": { "question": "…", "topicTitle": "JavaScript", "subtopicTitle": "Event loop", "level": "middle" }
    }
  ]
}
```

При загрузке файла заметки сливаются: побеждает более свежая по `updatedAt`.
